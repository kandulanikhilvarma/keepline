    Put my words
    on my iPhone.

    You can test a real rectangular widget with the free Scriptable app. No Mac or developer membership is needed for this route.

    1. Install the widget host.

      Get Scriptable from the App Store. Keep Keepline open in Safari.

    2. Copy your personal widget.

      Save at least one line above. Tap Copy widget code. Open Scriptable, tap +, paste the code, and name the script Keepline. Tap its play button to preview the rectangle.

      If copying is blocked, tap the code, select all, and copy it yourself.

      File route: download Keepline.js, then use Files to move it into iCloud Drive → Scriptable, if that folder exists. Open Scriptable and run Keepline. The copy route also works without iCloud Drive.

    3. Add the rectangle.

      Touch and hold your home screen. Tap Edit, then Add Widget. Search for Scriptable and choose its medium rectangular widget. Touch and hold the new widget, tap Edit Widget, and select the Keepline script.

      On older iOS versions, use the plus button to open the widget gallery.

    Save a line to prepare your widget file.

    When you change your saved lines or settings, copy the new code into the same Keepline script and run it again. The browser and Scriptable do not sync automatically.

    Add the personal editor from Safari

    In Safari, tap Share, then Add to Home Screen. This shortcut opens My Keepline. Scriptable supplies the actual widget. Open this page once online and wait for the offline-ready message before testing offline.

    Scriptable may sync scripts through iCloud if you enable that feature. Your generated widget makes no network requests. iOS can delay widget refreshes. Installation and rendering on your own iPhone still need your device test.
